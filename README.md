# Weather App

A simple weather app that shows the current temperature and wind speed for any city.

**Live demo:** https://albenisahamidi.github.io/WeatherApp/

## Features
- Search weather by city name
- Real-time data from the Open-Meteo API
- Error handling for empty input and unknown cities
- Responsive design

## Built with
HTML, CSS, JavaScript (Fetch API, async/await)
